# Ювелирные изделия — каталог

Статический веб-каталог коллекций: 13 линий, 27 изделий в золоте 585°.

## Что умеет

- Сетка карточек с фильтрами по камню, типу изделия и оттенку металла
- Поиск по названию, артикулу, металлу и описанию
- Карточка комплекта: съёмка со всех ракурсов, таблица состава (изделие, артикул, размер, вес), спецификация, рекомендации по уходу
- Подборка для заявки — сохраняется в браузере, копируется готовым текстом со всеми артикулами
- Светлая и тёмная тема, адаптив от 400 px

## Структура

```
index.html          весь каталог: разметка, стили, скрипт и данные в одном файле
img/<slug>-card.webp    кадр для карточки в сетке (900×900)
img/<slug>-look.webp    съёмка комплекта для подробной карточки
img/backdrop.webp       фоновая съёмка страницы
```

## Как править

Данные каталога лежат одним массивом `CATALOG` в начале `<script>` в `index.html`.
Поля линии:

| Поле | Значение |
|---|---|
| `id` | артикул линии, например `AV-07` |
| `slug` | имя файлов изображений в `img/` |
| `name`, `line`, `desc` | название, подзаголовок, описание |
| `stone`, `color` | камень и цвет метки в фильтре |
| `metal`, `tone` | металл; `tone` — `Жёлтое`, `Розовое` или `Белое` (по умолчанию жёлтое) |
| `types` | типы изделий для фильтра |
| `pieces` | состав: `art`, `n`, `spec`, `size`, `w`, `price` |
| `care` | уход |

Новый камень, тип изделия или оттенок металла появляется в фильтрах сам — списки строятся из данных.
Поле `price` в выдаче не показывается: цены убраны из интерфейса, значения оставлены на случай,
если их понадобится вернуть.
