# The Goldsmith

Сайт ювелирного ателье: обложка и лента съёмок со свайпом.
Имя проекта для деплоя: `the-goldsmith`.

## Страницы

- `index.html` — сайт; лента кадров встроена разделом «Съёмки»
- `gallery.html` — та же лента во весь экран, без интерфейса

## Как листать кадры

- Телефон: свайп влево-вправо
- Мышь: стрелки по краям ленты
- Клавиатура: ← → (когда лента в фокусе)
- Точки под лентой — переход к любому кадру
- В полноэкранной версии клик по фотографии увеличивает её

## Структура

```
index.html             сайт: разметка, стили и скрипт в одном файле
gallery.html           полноэкранная листалка
img/<slug>-look.webp   кадры лент
img/<slug>-card.webp   квадратные кадры, остались от прежнего каталога
img/backdrop.webp      фоновая съёмка обложки и листалки
```

## Кнопка «Добавить кадры»

Загруженные фотографии хранятся в Vercel Blob и видны всем посетителям с любого
устройства. Кадр сжимается прямо в браузере (длинная сторона 1600 px, webp) —
иначе запрос не уложится в лимит Vercel в 4,5 МБ.

### Что нужно включить один раз

Vercel → проект → **Storage** → Create Database → **Blob** → подключить к проекту.
Переменная `BLOB_READ_WRITE_TOKEN` появится сама, после этого сделать **Redeploy**.

Пока хранилище не подключено, кнопка загрузки не показывается и сайт
работает как обычная листалка встроенных кадров.

### Как пользуются

Нажать «Добавить кадры» и выбрать файлы — кадры встают в конец ленты
и сразу видны всем посетителям, в том числе в `gallery.html`.
Крестик в углу кадра убирает его из хранилища.

Загрузка открыта без пароля: залить и удалить кадр может любой, кто откроет сайт.

### Серверная часть

```
api/shots.js    GET  — список кадров
api/upload.js   POST — приём кадра, заголовок x-upload-key
api/delete.js   POST — удаление кадра по url
```

На GitHub Pages функции не работают: там страница покажет только встроенные кадры.

## Как править

Порядок и состав кадров — массив `SHOTS` в начале `<script>`; он есть в обеих
страницах и должен совпадать. Это имена файлов `img/<slug>-look.webp` без суффикса.
Добавить кадр — положить файл в `img/` и дописать имя в оба массива;
точки появятся сами.

Прежняя версия с каталогом, фильтрами и спецификациями осталась в истории git:
`git show cf30108:index.html`.

## Публикация

Сборка не нужна. GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
