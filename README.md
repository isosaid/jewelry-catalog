# The Goldsmith

Полноэкранная листалка съёмок ювелирных изделий — 13 кадров, без текста и интерфейса.
Имя проекта для деплоя: `the-goldsmith`.

## Как листать

- Телефон: свайп влево-вправо
- Мышь: стрелки по краям экрана или колесо
- Клавиатура: ← → , Home, End
- Точки внизу — переход к любому кадру
- Клик по фотографии увеличивает её, повторный клик возвращает

## Структура

```
index.html             вся страница: разметка, стили и скрипт
img/<slug>-look.webp   кадры листалки
img/<slug>-card.webp   квадратные кадры, остались от каталога
img/backdrop.webp      фоновая съёмка, осталась от каталога
```

## Как править

Порядок и состав кадров — массив `SHOTS` в начале `<script>`: это имена файлов
`img/<slug>-look.webp` без суффикса. Добавить кадр — положить файл в `img/`
и дописать имя в массив; точки внизу появятся сами.

Прежняя версия с каталогом, фильтрами и спецификациями осталась в истории git:
`git show cf30108:index.html`.
